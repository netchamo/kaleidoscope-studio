# קליידוסקופ

עורך וידאו שרץ בדפדפן ומותקן על מסך הבית באייפון, בלי חנות אפליקציות.

- צבע: סגנונות שנמדדו מקאפקאט, המרה מכוילת לצילומי אייפון, ריבוע גוון וצבע, תיקון ידני
- אפקטים: זוהר, הילה, חלומיות, ערפל, גרעיניות, גרעיניות זוהרת, הבזק אור, שוליים בכמה סגנונות, אור באמצע
- עריכה: כמה קליפים, חיתוך, פיצול, כניסה ויציאה הדרגתיות לתמונה ולשמע, זום ידני
- שמע: ריוורב של חללים, דיליי מסונכרן לקצב, אקולייזר, קומפרסור, מדים, מוזיקה חיצונית
- ייצוא: מותאם לוואטסאפ, שיתוף ישיר

הכלים לכיול נמצאים בתיקייה `calib`.
